# Kelime Widget

Native iPhone app + widget extension for learning English words from the lock screen and home screen.

- `design/`: final screen and widget designs (open `design/Kelime Widget.dc.html` in a browser). Visual source of truth.
- `docs/design-prompt.md`: design brief (screens, states, free/Pro rules, Turkish copy).
- `docs/BUILD_PROMPT.md`: technical build spec.
